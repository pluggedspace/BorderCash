# Security Policy

## Reporting a Vulnerability

We take the security of BorderCash seriously. If you believe you have found a security vulnerability, please report it to us responsibly.

### How to Report

Please do not open a public issue for security vulnerabilities. Instead, send an email to `support@border.cash` (or the support email defined in your environment settings) with the following information:

1.  **Description**: A detailed description of the vulnerability.
2.  **Steps to Reproduce**: Clear, step-by-step instructions on how to reproduce the issue.
3.  **Impact**: The potential impact of this vulnerability.
4.  **Suggested Fix**: If you have a suggestion for a fix, please include it.

### Our Process

Once we receive a report, we will:
1.  Acknowledge receipt of the report.
2.  Investigate the issue to confirm the vulnerability.
3.  Work on a fix and coordinate with the reporter for a disclosure timeline.
4.  Notify the reporter once the fix is deployed.

Thank you for helping us keep BorderCash secure!
